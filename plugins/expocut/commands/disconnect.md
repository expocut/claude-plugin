# Disconnect from ExpoCut

Tell the user how to unpair, in two short steps:

1. In Claude Code, run `/plugin`, open the **Installed** tab, select **expocut**, choose **Configure options**, and clear the **Server URL** and **Bearer Token**. Then run `/reload-plugins`. Disabling or uninstalling the plugin also removes it.
2. The token keeps working on the phone until it is revoked. To revoke it, tap **Rotate** in ExpoCut → Settings → AI Agent (MCP Server).
