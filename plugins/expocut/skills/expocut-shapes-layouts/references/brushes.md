Generated from the live catalog. Pass the id to add_brush_layer `brush`. "aspect" is width/height of the stroke design box: use it to pick canvasRelativeWidth/Height that do not distort the stroke (height% = width% x canvasAspect / aspect on a W:H canvas, e.g. on 9:16 a 3.0-aspect stroke at 60% width needs 60 x 0.5625 / 3.0 = 11.25% height). Brushes are shape layers of type custom_path, so every shape tool (set_shape_fill, set_shape_outline, set_shape_glow, set_shape_style, set_shape_canvas_relative_size) applies; set_shape would replace the stroke with a preset silhouette, so do not call it on a brush.
