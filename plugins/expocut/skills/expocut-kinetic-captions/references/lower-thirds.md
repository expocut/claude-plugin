# Lower-third catalog (list_lower_thirds, 180 presets)

Generated from the live catalog. Pass the id to add_lower_third_layer as presetId. "lines" is how many text lines the preset has; pass that many strings in `lines` (extra strings are ignored, missing ones keep the placeholder). Categories: accent, news, corporate, creative, minimal, boxed, split, framed, trend (kinetic title cards), fx (fill / mesh / glow / keyframe-colour / motion-path looks, incl. 12 RTL presets with ids starting fx-urdu- or fx-arabic-). The five urdu-* presets in trend are RTL too. RTL presets use a Nastaliq face and right alignment; pass Urdu/Arabic strings in `lines`.
